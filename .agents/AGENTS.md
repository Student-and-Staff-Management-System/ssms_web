# Design & UI Guidelines for SSMS

- **No AI Slop / Vibe-Coded Aesthetics**: Avoid over-engineered, glossy template tropes like random decorative emojis, excessive linear gradients, glowing borders, floating drop shadows, or 20px blob-rounded cards.
- **Clean Enterprise Aesthetics**:
  - Border radii: 6px - 8px for standard cards, inputs, and buttons.
  - Crisp typography: Use `Plus Jakarta Sans` or `Inter`, high contrast body text (`#1e293b`), clear font weights (500/600/700).
  - High functional density: Clean 1px solid borders (`#cbd5e1` / `#e2e8f0`), subtle neutral backgrounds (`#f8fafc`).
  - Solid, intentional brand color: Signature SSMS sage-teal (`#5a7d7c` / hover `#4a6b69`) without multi-color gradient overlays.
  - Professional controls: Clean, quiet focus states, functional data tables, clear semantic badges (`.badge-new`, `.badge-exists`).
